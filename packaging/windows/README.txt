didj - a LeapFrog Didj emulator

Double-click didj.exe to play. The first time, it offers to download the
Didj's software and games from archive.org (about 1.2 GB); then choose a
game from the list.

If Windows says it "protected your PC", click "More info", then "Run anyway".

Keys: arrow keys = pad, X = A, Z = B, A/S = shoulder buttons, Enter = pause,
H = hint, Esc = home, F11 = fullscreen. Game controllers work too.

Downloads and saves are kept in %LOCALAPPDATA%\didj.

didj-fetch.exe and didj-run.exe are command-line tools; see
https://github.com/collintfr/didj for what they do.
